## [0.1.0] - 2026-08-28

### Added

- Local dotenv profile resolution with no shell evaluation.
- Host, operation, required-variable, JSON-field, and body-size policies.
- Explicit production acknowledgement and default-deny production operations.
- Value-free JSONL decision receipts and scriptable JSON output.
- Guarded command execution with resolved profile variables.
- Offline static documentation and browser-only policy simulator.
