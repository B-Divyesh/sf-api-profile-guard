    Policy plate / 03

    Production is not a color.

    A theme can be missed. A failing policy cannot. Production requires an exact host, an explicit operation allowlist, and a typed acknowledgement.

    apg.tomllocal / reviewable
    # Secrets stay in .env.prod
[profiles.production]
env_file = ".env.prod"
required = ["API_BASE_URL", "API_TOKEN"]
credential_class = "live"
production = true
acknowledgement = "production"

allowed_hosts = ["api.example.com"]
allow = ["GET /v1/*", "POST /v1/orders"]
deny = ["* /v1/admin/*"]
    ⊘

    No shell evaluation

    Dotenv values are parsed as literals. Expansion and substitution are rejected.

    ⌁

    No secret receipts

    Receipts record the decision and non-secret fingerprint—not headers, values, queries, or bodies.

    ↯

    No early connection

    apg run does not spawn curl, Bruno, or your script until every check passes.

    Release record / 04

    A receipt you can keep. Nothing you need to hide.

    JSON decisions and JSONL receipts fit CI without sending your request history anywhere. Allowed runs keep child stdout clean for response pipelines.

    $ apg check --profile production --method DELETE \
    --url /v1/users/42 --ack-production production

✕ BLOCKED  production · 8C31F2A091E4
  DELETE api.example.com/v1/users/42
  - operation_not_allowed
  receipt: .apg/receipts.jsonl

No child process started. No network connection opened.
