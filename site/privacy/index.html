Plain-language policy

Privacy

Effective August 28, 2026

The CLI

API Profile Guard runs on your machine. It does not send profile variables, secrets, request headers, bodies, history, or receipts to us. It has no telemetry. The only network request made during guarded use is the one made by the child command you explicitly approve.

Decision receipts are local JSONL files at the path you configure. They contain profile names, non-secret fingerprints, methods, hosts, paths without query strings, decision codes, credential-class labels, and timestamps. You control and may delete those files.

This website

The website has no analytics, advertising, cookies, accounts, forms, or third-party runtime scripts. The preflight simulator runs entirely in your browser and does not transmit or persist its inputs. A service worker stores public site files in your browser cache so the documentation works offline.

Infrastructure logs

Our static host may process short-lived security and delivery logs such as IP address, requested path, user agent, and time. We do not combine these logs with profiles or sell them. The repository does not configure analytics.

Your choices

You can remove the site's offline cache through your browser settings and remove local receipts from your project. Because the product has no account, there is no hosted profile to delete.

Contact

Open a privacy issue in the public repository. Do not include secrets or production request details.
